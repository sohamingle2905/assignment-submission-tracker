# Assignment Submission Tracker

A simple college project for keeping track of assignments and their submission deadlines. This is the basic project setup; assignment tracking features can be added in later stages.

## Technology stack

- Node.js 24 LTS
- Express.js
- HTML, CSS, and vanilla JavaScript
- SQLite (prepared as a project dependency for later use)
- Jest and Supertest (planned for later testing)
- GitHub Actions, GitHub, and Render (planned for later use)

## How to install

1. Install Node.js 24 LTS.
2. Open a terminal in the project folder.
3. Install the project dependencies:

   ```bash
   npm install
   ```

## How to run

Start the server:

```bash
npm start
```

Open [http://localhost:3000](http://localhost:3000) in your browser. To check the server health, visit [http://localhost:3000/api/health](http://localhost:3000/api/health).
